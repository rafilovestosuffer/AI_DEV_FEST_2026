# Documented Domain Assumptions

Every insight, forecast, and plan generated by Sathi transparently cites its underlying assumptions (architecture §7.1, invariant 14: every assumption is named, configurable and recorded — no hidden constants, no invented upay facts).

Values below are read from the config files in `config/` — the single source of truth at runtime — and every figure shown to a user carries the matching assumption label in its evidence block.

| Assumption ID | Config Key | Current Value | Justification & Source |
| :--- | :--- | :--- | :--- |
| `FEE_CASHOUT_RATE` | `fees.cash_out_bps` (`config/fees.yaml`) | **150 bps** (1.5%), min fee ৳5 (`cash_out_min_paisa: 500`) | Illustrative agent cash-out tariff, calibrated against standard MFS market benchmarks. A placeholder until a partner's published tariff replaces it — never presented as an upay fact. |
| `FEE_DIGITAL_PAYMENT_RATE` | `fees.digital_payment_bps` (`config/fees.yaml`) | **0 bps** (free) | Merchant QR payments in MFS wallets are typically free for retail customers, so substitution savings equal the full cash-out fee. |
| `ESSENTIALS_PER_DAY` | `thresholds.essentials_per_day_paisa` (`config/thresholds.yaml`) | **৳350** (35,000 paisa) | Minimum daily spend on essentials (food, transport, utilities share) for the hero income band; the survival baseline behind the safety buffer. |
| `SHORTFALL_HORIZON_DAYS` | `thresholds.shortfall_horizon_days` (`config/thresholds.yaml`) | **21 days** | A shortfall alert follows the balance path until the next expected income, capped at this many days ahead. The user-facing early warning uses a 7-day lead (`shortfall_alert_lead_days: 7`). |
| `REPLACEABLE_FOLLOW_DAYS` | `cashout_detector.follow_days` (`config/app.yaml`) | **2 days** | A cash-out followed within 48 h by a digital-capable merchant payment of ≥ 50% of the withdrawn amount (`min_amount_frac`) counts as "used the cash" — i.e. plausibly replaceable by a direct digital payment. |
| `CONFIDENCE_MIN_TXNS` | `thresholds.min_history_transactions` (`config/thresholds.yaml`) | **20 transactions** | Minimum sample size required to grant normal confidence label. |
| `CONFIDENCE_MIN_DAYS` | `thresholds.min_history_days` (`config/thresholds.yaml`) | **45 days** | Minimum observation span required to grant normal confidence label; below it the forecast falls back to persona priors with confidence "low". |

Related configurable assumptions that surface in evidence blocks: the shortfall floor (3 days of the user's own median daily outflow, `shortfall_floor_days`), the planner's minimum buffer (`min_buffer_days: 3`), and the repeat-cash-out habit threshold (`cashout_detector.min_repeat: 3` withdrawals to the same agent).
